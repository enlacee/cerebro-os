# Servicio – Android

Aníbal desarrolla y publica apps Android **reales en producción**. No es teoría:
tiene apps propias y de clientes vivas en Google Play.

## Qué ofrece

- Desarrollo de apps Android en **Kotlin** (Jetpack Compose).
- Arquitectura **Frontend + Backend simple** (Android + Google Sheets/Apps
  Script o API propia) para **reducir el costo de servidores casi a 0**.
- Integración de **Login (Google), API y Webhooks**.
- **Monetización**: AdMob (publicidad) y suscripciones (SaaS).
- Flavors / variables de entorno (debug vs release, FREE vs PRO).
- Firma correcta (keystore), optimización (R8/ProGuard), AAB para Play Store.
- **Publicación completa en Google Play** (ver `productos/play-store.md`).

## Stack y herramientas

Android Studio · Kotlin · scrcpy (mostrar el teléfono) · Terminal Linux ·
Google Apps Script · Google Sheets como DB.

## Casos reales

OkeyPay, FastPay, Rapitaller (Android + iOS), La Voz Radio, Radio Mila,
App "My Linux" / Aníbal Linux. Ver `ventas/casos-exito.md`.
