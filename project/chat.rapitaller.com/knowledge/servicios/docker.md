# Servicio – Docker

Docker forma parte del stack de Aníbal para desplegar y aislar servicios en
servidores (VPS o casa).

## Qué ofrece

- Contenerización de aplicaciones (web, APIs, bases de datos).
- Despliegue y orquestación básica de servicios en un servidor.
- Ayuda con Docker incluida en los planes de **Acompañamiento Tecnológico**
  (Brazo Derecho **$100/mes** e Implementación **$300/mes** — ver
  `servicios/acompanamiento-tecnologico.md`).

## Importante (enfoque de venta)

El cliente **no compra "Docker"**: compra *"quiero que mi aplicación funcione"*.
Docker es un medio, no el producto. Siempre se vende el **resultado**:
> "Te ayudo a llevar tu aplicación o sistema desde el problema técnico hasta
> producción."

## Cómo se cotiza

Dentro de acompañamiento mensual, o proyecto a medida vía consultoría técnica
(`servicios/asesoria.md`).
