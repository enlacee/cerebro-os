# Ventas – Casos de éxito

> *"La gente compra evidencia."* Estos son proyectos reales, verificables.

## Apps en Google Play (propias y de clientes)

- **OkeyPay** — app de verificación de pagos (Yape) con API y webhook.
  `com.anibalcopitan.okeypay`. Caso usado en el Curso Android SaaS.
- **FastPay** — app de pagos (comparte backend con OkeyPay).
- **Rapitaller / Rapitaller Plus** — marketplace automotriz (dueños ↔ talleres ↔
  tiendas). **Android + iOS**, backend en DigitalOcean, publicada tras pasar la
  revisión de App Store.
- **La Voz Radio**, **Radio Mila** — apps de radio.
- **App My Linux / Aníbal Linux**.

Página de desarrollador: https://play.google.com/store/apps/developer?id=AnibalCopitan.Com

## Proyectos de infraestructura / servidores

- **Studio8Record** — servidor Ubuntu en casa con Caddy + Apache/PHP/MySQL + SMB,
  dominios y subdominios con HTTPS automático, almacenamiento en `/mnt/storage`.
- **Tu VPS en Casa** — múltiples clientes montando servidores caseros.

## Automatización / IA

- **Automatización TikTok Live** (bot de comentarios → Google Sheets).
- **Bots de captura de clientes**, integración de APIs, web scraping.
- **Sistemas Android** y backends con Google Sheets + Apps Script.

## API real

- **API OkeyPay** (Developer Beta): obtener pagos registrados desde Google Sheets,
  con webhooks bajo solicitud para integraciones.

producción"* → vende mucho más que teoría.
