# Crea tu sistema con Google Sheets + Apps Script

> 🗣️ **Cuándo ofrecerlo:** cuando el cliente dice *"quiero crear mi sistema con
> Google Sheets"* o quiere un backend/registro sin pagar servidores.

Recurso para construir tu propio sistema usando **Google Sheets como base de
datos + Apps Script como backend**. Se comparte **código fuente** y plantillas
para adaptar a tu negocio, con mi asesoría para implementarlo.

## Precio

- **$20** — código fuente + plantillas **+ asesoría Plan 1** (te guío para
  armarlo). Es el modelo de recurso: $20 = recurso + sesión 1 a 1.
- 🎁 **Gratis / sin límites** dentro del **Plan Brazo Derecho ($100/mes)** y
  **Plan Implementación ($300/mes)**.

## Qué incluye

- 📊 Sistemas listos en Google Sheets (DB real).
- ⚙️ Código con Apps Script (backend simple).
- 🌐 Ejemplo web conectado (HTML + fetch).
- 🔐 Ejemplo con login usando Google.
- 🧠 Plantillas listas para adaptar a tu negocio.

## Casos de uso

Registro de usuarios · formularios conectados a Sheets · mini-SaaS sin backend ·
automatización de procesos.
