# Producto – Pasarela de Pago (Cobra con 1 Link)

Página de pago simple para vender tus productos o servicios con **un solo
enlace**. Muestra precio y descripción, métodos de pago (Yape, PayPal, Binance),
y registra automáticamente en **Google Sheets**.

## Precio

- **$20** — incluye el código de la pasarela **+ la asesoría Plan 1** (te guío
  para implementarla). Pedirla suelta o tomar la Consulta $20 es lo mismo: $20 =
  recurso + asesoría.
- 🎁 **Gratis** si ya tomas la **Consulta Técnica ($20)** o dentro del **Plan
  Brazo Derecho ($100/mes)** (ahí accedes a cualquier recurso sin límites).

- Demo: https://anibalcopitan.com/pago/?p=IgbcWMvu
- Documentación: https://blog.anibalcopitan.com/2026/03/pasarela-de-pago-simple-para-productos.html

## Variante "Cobra con 1 link sin web" (plantilla)

Sistema **Google Sheets + Yape** para generar links de pago en minutos.
Entrega vía Drive (plantilla + código + manual); el cliente hace "Crear copia".
